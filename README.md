### 🎯 Aim
Calculate model performance metrics such as accuracy, precision, recall and F1-score using a simple classification dataset.

### 📦 Dataset Source
scikit-learn built-in Breast Cancer dataset (load_breast_cancer)

### 🚀 Quick Start (Practical Examination)
1. **Install Dependencies:**
   ```powershell
   python -m pip install -r requirements.txt
   ```
   *(Or run `.\setup.ps1` in PowerShell)*

2. **Execute Experiment:**
   ```powershell
   python main.py
   ```

3. **Output:**
   - Detailed terminal logs with predictions and evaluation metrics.
   - High-resolution plot generated and saved in this directory.
